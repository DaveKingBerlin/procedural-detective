# Procedural Detective — Demo Video Storyboard (< 3 minutes)

Target total: **~2:35**, comfortably below the 3-minute submission limit.
Phase 15 structure: concept → six-line prompt → Asset Oracle → 3D
investigation → accusation → reveal → environment montage → differentiator.

---

## 0:00–0:15 — concept

> "AI can generate a world. But can that world have a real, provable truth?"

- Landing page on screen: *Procedural Detective — describe a crime, AI builds
  a logically solvable 3D investigation.*
- One sentence over the static page: different prompts → different worlds,
  every world validated.

---

## 0:15–0:30 — six-line prompt

- Click **Generate a New Mystery**; type the six-line showcase prompt into the
  natural-language textarea:

  ```text
  Victim: Sarah Miller
  Murderer: Thomas Reed
  Motive: €240,000 embezzlement
  Weapon: Kitchen knife
  Time: 22:17
  Witness: Emily Reed
  ```

- Hit **Generate case**.

---

## 0:30–0:45 — Asset Oracle / generation progress

- Generation progress screen: *Creating case → Building world → Generating
  evidence → Checking consistency → Preparing investigation*.
- Voiceover: the Asset Oracle resolves every requested object against the
  catalog + the five environment kits — a safe procedural fallback only when
  nothing sensible exists — and the deterministic solver validates the world.

---

## 0:45–1:25 — generated environment, direct object clicking, evidence

- Enter the 3D scene (the generated apartment).
- Move the pointer: hover ring + label tooltip appear over the **knife**;
  click it — discovery toast, evidence panel with the registry swatch.
- Click the **laptop** → read the email; note the discovered evidence caption
  over the knife and the discovered labels in the object list.
- Show the elevated highlight: hovering an interactable, then opening a panel
  so the object keeps its emissive focus while the panel is open.

---

## 1:25–1:50 — accusation

- Open the accusation screen from the scene.
- Fill in WHO / WHY / WEAPON / WHEN and confirm.
- Submit — an accusation is now on file for the case.

---

## 1:50–2:10 — reveal

- The reveal screen: the immutable truth (WHO, WHY, WEAPON, WHEN), your
  accusation compared per dimension, and the overall verdict.
- One line: "The world is generated; the truth was validated before it ever
  reached you."

---

## 2:10–2:35 — quick montage of other environments/prompts

- Rapid cuts, one scene each (~5s):
  - **Office** — letter opener + procedurally generated custom trophy.
  - **Hotel suite** — glass bottle + medication near the body.
  - **Warehouse** — wrench + rope.
  - **Mansion** — antique ceremonial letter opener + wristwatch.
- Brief captions: "same engine, different prompt → different world".

---

## 2:35–2:50 — architecture differentiator

- One clean frame:

  ```text
  Prompt
  → Truth & story generation
  → Asset Oracle
  → Environment + object resolution
  → Safe procedural asset generation when needed
  → World composition
  → Deterministic solvability validation
  → 3D investigation
  ```

- One line: "Everything generated, everything validated — the evidence the
  player sees is exactly what the solver proved the case with."

---

## 2:50 — final message

> "Procedural Detective — every generated mystery has a real answer."

- Logo / link overlay.
