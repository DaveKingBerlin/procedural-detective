pd-ollama-bridge — THIRD-PARTY NOTICES
=======================================

Version: 1.0.0
Project: Procedural Detective (https://github.com/DaveKingBerlin/procedural-detective)

This file lists the third-party software that is bundled inside the packaged
`pd-ollama-bridge` standalone binary, together with the applicable license. The
bridge application code itself is licensed under the MIT License (see the
`LICENSE` file in this archive). The inventory below was read from the released
binaries themselves (each bundled distribution's `*.dist-info` and embedded
module bytecode); where the binary does not record a package's version, the
version is shown as "not recorded in binary" rather than guessed.

The Windows and Linux artifacts are built on different platforms, so they do not
bundle an identical set. Components marked "(Windows only)" are present in the
Windows `.exe` and absent from the Linux binary.
